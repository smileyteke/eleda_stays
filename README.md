# Eleda Stays - React Website

A modern, responsive React website for Eleda Stays, featuring a clean design and comprehensive pages for hospitality services.

## 🌟 Features

- **Home Page**: Engaging hero section with featured properties and testimonials
- **About Page**: Company story, team, mission, and values
- **Services Page**: Comprehensive service offerings and packages
- **Contact Page**: Contact form, business information, and FAQ section
- **Responsive Design**: Mobile-friendly layout that works on all devices
- **Modern UI**: Clean, professional design with smooth animations

## 🚀 Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn package manager

### Installation

1. Clone or download the project
2. Navigate to the project directory:
   ```bash
   cd "Eleda Stays"
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application

Start the development server:
```bash
npm start
```

The application will open in your browser at `http://localhost:3000` (or another port if 3000 is in use).

### Building for Production

Create a production build:
```bash
npm run build
```
